# One More Help

Public help for **One More: Puzzle Rivals** (iPhone). Plain static HTML on GitHub Pages —
no build step, no Jekyll (`.nojekyll`). A push to `main` is live in about a minute.

- Live: https://mytombrown.github.io/one-more-help/
- App repo: `mytombrown/One-More` (`~/Apps/one-more`). Every fact here is read from that code;
  change the app, change this page in the same pass.
- Privacy policy lives on the legal site, never here: https://legal.mytombrown.com/one-more/privacy/
- Screenshots in `assets/` come from the app's UI tests (`docs/screenshots/`), resized to 900 px.
- Custom domain (e.g. `onemore.mytombrown.com`) is not set up: it needs a Route 53 CNAME — Tom's hands.
